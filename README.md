# FlowTask V2

The second version of FlowTask, a browser task manager with an interface in French. It is the same app as the single-file first version, split into `index.html`, `style.css` and `script.js`.

## Features

- Tasks with filters, search and drag and drop
- Dashboard, calendar and Pomodoro focus timer
- Per-task timers and deadline notifications
- Dark mode

## Run

Open `index.html` in a browser. No build step and no dependencies.
